# E-Commerce Sales Prediction

**Description:** Used regression modeling to analyze the impact of price, discount, and marketing spend on units sold in an e-commerce dataset.

**Tools Used:** Python, Pandas, Scikit-learn, Matplotlib

## 📌 What I Did
- Conducted EDA and feature engineering
- Built and evaluated regression models
- Created correlation heatmaps and marketing impact visuals
- Summarized results in a business-focused report
